# CPP lexical timing adapter

Pinned CLI -ojf already emits token text and offsets (including special tokens and zero-duration subwords). The previous serial and batch adapters discarded these via words=[]. Shared `cpp_words.parse_transcription` now groups space-delimited Turkish/English lexical words, joins Unicode subwords and punctuation, excludes the pinned [_...]-style control markers, and validates exact reconstructed text and monotone in-segment timing. A zero-duration subword inside a positive-duration word is retained; a whole zero-duration word, missing offsets, inconsistent text, multiword token or invalid timing causes full-segment word fallback. Original segment text is always retained for timing fallback.

Structural corruption is different: malformed segment schema raises a content-free ValueError for the entire call, preserving the adapter's original all-or-nothing behavior. We do not silently skip bad segments. Claude reviewed the parser, timing and compatibility. Its suggestion to wrap malformed segments informed explicit validation; per-segment skipping was rejected because it would hide text loss. Downstream uses no required word probability field. Original confidence_unavailable remains true; optional metrics.word_timing=cpp_token_heuristic identifies approximate token-derived timing, not forced alignment.

Verification: adapter/unit coverage includes Turkish Unicode, punctuation, zero-duration subwords/whole words, bad offsets, exact text preservation, malformed schema, single/batch routing and a two-speaker split. Actual pinned no-prompt synthetic probe: 2 segments, 1 with valid word groups, 4 timed words; original text preserved. A phrase in the other segment has four whole zero-duration words, so its alignment is correctly unavailable.

Repeated matched four-clip benchmark with normal vocabulary: serial 23.128/24.875s, WER .1818, 21 timed words; window 6.186/5.971s, WER 0, only 11 timed words of 22 reference words. No observed bounds/gap violations among available words; missing coverage is NOT a pass for speaker-boundary alignment. Report `benchmarks/results/cpp-window-with-words-2026-09-08.json`. Synthetic WER is not real-meeting accuracy. Unrestricted live windows remain OFF.

Preserve original silence and 12s bound; leave cross-speaker/unknown/overlapping cases separate. That can reduce redundant encodes without depending on missing word timestamps across speaker transitions. Requires tests and native measurement before enabling.
