# Lower audio residency during same-meeting retry

Retry previously held the entire mono float32 recording while each native ASR child ran. Simply assigning audio=None did not reduce the measured physical footprint: NumPy/libc retained freed allocations. The revised retry-only path uses an anonymous mmap-backed analysis array, reads the immutable assembled mono16k snapshot directly into it, runs unchanged full-recording VAD/diarization, releases its reference and seek-reads the original VAD regions for ASR and embeddings. No segmentation, model, decoder, diarization threshold or identity policy change.

Ownership matters: the ndarray owns mmap through .base; no manual mmap.close or enclosing mmap context forces invalidation. Retained views and exception tracebacks keep storage valid until their last reference goes away. Original Sherpa code still supplies an explicit float32 copy to the synchronous native call. Silence, truncated reads, nonfinite samples and unsupported resampling/live requests are handled explicitly. The outer SoundFile context closes on all exits. This path is only enabled for retry's private assembled mono16k snapshot; retry hashes sources and copies again before committing.

Claude Code reviewed coordinate/sample equivalence and flagged lifetime/traceback risks and short reads. These informed the ownership-based implementation and new tests; no reliance on a presumed BufferError safeguard for NumPy views. Source files remain immutable through retry's existing snapshot/digest contract, not through making the temporary analysis ndarray read-only.

Measured with synthetic 3154-second PCM and fake models in separate child processes: Python footprint at ASR entry 532,448,144 bytes baseline vs 77,972,008 bytes bounded (~433.4 MiB reduction). Report: `benchmarks/results/bounded-final-memory-2026-09-08.json`. Reproduce with `.venv/bin/python scripts/benchmark-final-audio-memory.py` from repo root. This isolates audio storage only; it does NOT measure full native model memory, prove pressure-free operation or benchmark recognition quality.

Validation: six bounded-audio tests cover exact PCM input/embedding/timestamp/segment equivalence, release before ASR, retained views after success/failure, short reads and rejected modes. Five pipeline, 31 retry and 20 live tests pass. Existing live/default import behavior stays on its original path. Small native end-to-end and full real-meeting recovery with the revised path remain pending. Do not repeat the long recovery until the short native/memory check passes.
