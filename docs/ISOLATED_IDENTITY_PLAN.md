Narrow scope: retry, CPP, isolated Sherpa, Resemblyzer only. Use lightweight model-id/weight resolver without importing Torch/Resemblyzer runtime in parent. Keep exact hash/model-ID format. Finish each source ASR first; preserve existing segment text/times/flags/order and exact embedding sample bounds and ambiguity exclusion. Then one bounded direct worker loads Resemblyzer and computes that source's vectors in the original order from the same private immutable float32 snapshot. Worker exits before next source's ASR. Parent applies store.identify in original order with identical thresholds/model ID. Default live, cluster/ECAPA and normal imports remain unchanged. No auto enrollment or paid API.

Worker contract: bounded frame/span/request counts and output bytes, explicit indexes and exact count, finite valid vectors or None only, no partial success, snapshot/weight signatures plus model-ID verified before/after. Use existing supervisor/lifeline, OS-pressure/footprint guards and cancellation. No extra complete audio array; seek/read only exact segment samples. Pipeline result list is already held per source; retain only bounded per-segment sample-span descriptors, not audio copies. Full retry commit remains atomic; failed worker leaves original transcript and completed ASR/diarization checkpoints intact.

Acceptance: failing tests for no parent embedding load before/during ASR, all ASR calls before first embedding, exact spans/clipping/ambiguity/short audio, matching segments and saved identity decisions, multiple sources do not retain worker, child failure/cancellation cannot commit partial output, profile model hash equality, changed weight/snapshot rejects. Native public audio baseline vs worker vectors with numerical difference recorded and identical identity decisions; real process residency beforeASR lower using physical footprint (notRSS). Then complete real retry and evaluate live separately.
